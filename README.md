# Seller AI

Развитие существующего проекта на Next.js App Router, TypeScript, Tailwind CSS и React. Светлый интерфейс с зелёными акцентами, адаптивные страницы и локальные рабочие пространства магазинов. Это локальная версия владельца, а не готовый коммерческий сервис с регистрацией пользователей.

## Запуск на MacBook

Требуется Node.js 24 LTS. Из checkout с текущими изменениями:

```bash
cd avito-seller
npm ci
npm run dev
```

Откройте http://localhost:3000. AI-ученик — http://localhost:3000/learning. Не закрывайте Терминал. Если порт занят: `npm run dev -- --port 3001`. Production-режим: `npm run build`, затем `npm start`.

`localhost` означает компьютер, где запущен сервер. Облачный localhost не открывает облачное приложение на MacBook без поддерживаемого приватного проброса; подробности в `PREVIEW.md`. Эта версия не публиковалась в интернет. Если ваш checkout старее, сначала сохраните/перенесите новые коммиты из Codex; локальный запуск сам не получает неопубликованные изменения.

Для бесплатных функций `.env.local` не нужен. Новых npm-зависимостей в этом этапе нет. Установка npm-зависимостей требует сети; медиа после установки обрабатываются локально.

## Что работает

| Раздел | Реальная функция | Ограничение |
| --- | --- | --- |
| Обзор `/` | Счётчики текущего каталога и диалогов | Выручка и график явно демонстрационные |
| Товары `/products` | CRUD, поиск, остатки, статусы | Локальные записи; исходный магазин содержит демотовары |
| Сообщения `/messages` | Демо-переписки, ручной ответ, передача человеку | Ничего не отправляется на площадку |
| AI-ассистент `/assistant` | Сохраняемый чат по товарам, редактирование и копирование, пять стилей | Ответ предлагает локальный демоалгоритм, не LLM |
| AI-ученик `/learning` | Одобрение/отклонение, исправления, свои ответы, история версий, фильтры, экспорт и поиск | Примеры — справка, не переобучение модели |
| AI-продавец `/seller` | База знаний, сценарии/импорт, сравнение, ручные оценки, история/usage, будущие правила | Два демоалгоритма; реальные провайдеры требуют отдельного разрешения и настройки |
| AI-объявления `/listings` | Шаблоны по фактам, стили, правка, фото, сохранение и копирование | Без внешней AI-генерации и публикации, модерация не гарантируется |
| AI-фотостудия `/photo` | Реальные PNG: вписывание в формат, яркость, до 10 вариантов, до/после, история и скачивание | Не ретуширует, не удаляет фон и не создаёт новые ракурсы |
| AI-видеостудия `/video` | Реальный локальный ролик из фото, формат/длительность/подпись, предпросмотр и скачивание | WebM/MP4 по поддержке браузера; не AI-видео и не серверный MP4-конвейер |
| Аналитика `/analytics` | Наблюдения по локальным примерам, черновикам, заданиям и сохранённым API-попыткам | Нет достоверной конверсии и реального биллинга площадок |
| Настройки `/settings` | Магазины владельца, параметры, честные состояния интеграций | Нет фиктивной регистрации, авторизации, платежей или подключения Авито |

Все режимы автоматической отправки остаются выключенными. Можно подготовить список сценариев и интервал, но это не разрешение на отправку. Сложные вопросы требуют человека.

## Данные и сохранность

- Исходные ключи `ai-avito-seller:v1` и `seller-ai:lab:v1` сохранены для магазина `local-main`. Разрушительных миграций нет.
- Остальные магазины получают отдельные ключи каталога, лаборатории, чата, обучения, объявлений, медиа-заданий и политики. Исходники и результаты — Blob в IndexedDB, с workspace/store scope.
- Обучающие примеры содержат store/product ID, исходный и исправленный ответ, статус, пояснение, даты и историю правок. Поиск не включает другой магазин/товар, черновики или отклонённые примеры.
- Повреждённая исходная запись не перезаписывается демонстрационным набором. Показывается предупреждение; изменения раздела остаются в памяти.
- При заполнении хранилища показывается ошибка. Экспортируйте важные примеры/историю и скачивайте готовые файлы. JSON-экспорт заданий содержит метаданные и ID, не сами бинарные файлы; это не полная резервная копия IndexedDB.
- Приватный режим, очистка браузера и смена профиля влияют на локальные данные. Серверной БД, синхронизации вкладок/устройств, входа и резервных копий пока нет.
- Разделение магазинов в одном браузере не защищает от человека с доступом к тому же профилю и DevTools. Перед коммерческим использованием нужна серверная авторизация.

## Работа с обучающими примерами

В ответе ассистента или карточке сравнения выберите «Одобрить», «Исправить и обучить» либо «Неудачный ответ». Сохранённый исправленный пример можно оставить на проверку или явно одобрить. История сохраняет предыдущую версию. В отдельном разделе можно создать свой пример, удалить с подтверждением и проверить поиск по словам. Экспорт контекста подготовлен для будущих AI-запросов; внешней отправки по умолчанию нет. Одобренный пример не заменяет актуальную цену и характеристики товара.

## Медиа

Поддержаны JPEG, PNG, WebP до 8 МБ и 25 Мп; для будущих видео-заданий MP4/WebM до 30 МБ. Проверяются размер, MIME и сигнатура; изображения дополнительно декодируются. SVG/HTML не принимаются. До 10 исходников на задание.

Локальное фото не изменяет бренд/комплектацию и не скрывает повреждения. Варианты отличаются только яркостью/форматом. Генеративные задания из текста и обработка исходного видео остаются «Ожидает провайдера» без фальшивого прогресса и результатов. Стоимость неизвестна до выбора провайдера и тарифа, запросы не запускаются.

Локальное видео 3–30 секунд записывается в реальном времени через Canvas/MediaRecorder. Оставьте вкладку открытой и видимой. При закрытии/уходе задача прерывается; исходники сохраняются. В неподдерживаемом браузере показывается ошибка, а не фиктивное видео. Safari на реальном устройстве ещё требует ручной проверки.

## Настоящий AI и интеграции

Рабочие серверные границы сравнения Yandex AI Studio / DeepSeek / Qwen / GigaChat описаны в `SELLER_AI.md`. Ключи — только серверные переменные `.env.local`, исключённые из Git. Одних ключей недостаточно: нужны явный opt-in `SELLER_AI_ENABLE_REAL=true`, отдельный код администратора и разрешение владельца на расходы. Модели/ID и тарифы берутся из проверенной конфигурации, не выдумываются. Внешние API в этом этапе не вызывались.

Медиа-провайдеры не подключены; есть контракт `GenerativeMediaProvider`. Для реальной генерации потребуются серверный адаптер, согласие на передачу исходников, проверенная стоимость и разрешённые расходы. Авито не подключён, scraping и обходы не реализованы.

## Проверки

```bash
npm run typecheck
npm run lint
npm test
python3 tests/check_saas_schema.py
npm run build
npx playwright install chromium  # только если браузер ещё не установлен
npm run test:e2e
```

Для системного Chromium задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium`. Браузерные проверки используют production-сборку. Перед новым build остановите прежний production-сервер, чтобы тесты не переиспользовали устаревшие чанки.

Ход по этапам — `DEVELOPMENT_STAGES.md`, фактические результаты — `VERIFICATION.md`. Полный перечень изменённых файлов текущей задачи — `docs/CHANGE_REPORT.md`.

## Что нужно до коммерческого запуска

В `docs/SAAS_ARCHITECTURE.md` описаны следующий этап и границы: настоящие пользователи/сессии/роли, tenant-scoped серверные репозитории, БД и объектное хранилище, долговечная очередь, OAuth площадок, аудит, бюджеты, резервные копии и настоящая административная панель. `schema/saas-reference.sql` проверена только во временной памяти и не применяется к данным браузера. Платежи и платные ресурсы не подключены.
