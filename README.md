# DAVIO

**Меньше рутины — больше продаж.** Развитие существующего `avito-seller` на Next.js 16, React 19, TypeScript и Tailwind CSS. Отдельного проекта не создавалось.

Рабочий основной сценарий: локальный аккаунт → проект объявления → 1–10 фото → подтверждённые сведения → описание по шаблону → коррекция фото через Sharp → MP4 через FFmpeg worker → ZIP для ручной публикации.

Это работающая локальная версия, а не готовый публичный многосерверный SaaS. Внешний AI, маркетплейсы и платежи по умолчанию не подключены. Описание и чат честно обозначены как локальные алгоритмы.

## Запуск на MacBook

Нужны Git, Node.js **24 LTS** и FFmpeg с libx264/drawtext. Например, через уже установленный Homebrew: `brew install node@24 ffmpeg`. Убедитесь, что `node --version` показывает `v24.*`, а `ffmpeg -version` доступен. При необходимости следуйте инструкции Homebrew по PATH для Node 24.

```bash
git clone --branch work https://github.com/sultanyandavid-bit/avito-seller.git
cd avito-seller
npm ci
cp .env.example .env.local
npm run dev
```

В другом терминале, **в той же папке**:

```bash
npm run worker
```

Откройте **http://localhost:3000** в Chrome **на MacBook, где выполняются эти команды**. Создайте локальный аккаунт (пароль от 12 символов), нажмите «Создать объявление». Заполнять почту внешнего сервиса и подключать API для базового сценария не нужно. Регистрация здесь создаёт только запись на вашем сервере; письма не отправляются.

Если папка уже есть, повторно клонировать её не нужно. Обновляйте существующую ветку обычным `git pull --ff-only`, только при чистой рабочей копии. **Эта инструкция не означает, что новые изменения текущей задачи уже отправлены в GitHub**: статус сохранения и SHA см. в итоговом сообщении Codex.

Production-сборка для локальной проверки (не публикация):

```bash
npm run build
npm start
```

Если песочница блокирует служебный сокет Turbopack, поддерживаемый вариант — `npm run build -- --webpack`. Не пересобирайте приложение при работающем `next start`: сначала остановите процесс и затем запустите его заново.

Порт занят: `npm run dev -- --port 3001`. Если задан `DAVIO_APP_ORIGIN`, он должен совпасть с адресом в браузере, включая порт. Для worker порт веб-сервера не нужен.

## Что работает

- Четыре основных раздела: Главная, Объявления, Сообщения, Настройки. Обе темы, системная тема и reduced motion; мобильная нижняя навигация.
- Регистрация, вход/выход, профиль, смена пароля, серверные сессии с HttpOnly cookie, хранение только scrypt-хешей паролей и хешей токенов сессий.
- Серверные проекты, сохранение и повторное открытие, дублирование, архив/возврат, версии текста и защита от перезаписи более новой версии.
- Загрузка, проверка реального формата/декодирования и порядка фото. JPEG/PNG/WEBP до 15 МБ, максимум 40 MP и 10 исходников. HEIC требует предварительной конвертации.
- Независимое редактирование описания, исходников, обработанных изображений и видео. Текст состоит только из введённых фактов; неизвестные сведения не додумываются.
- Sharp: яркость, контраст, баланс цвета, мягкая резкость, кадрирование, размер и качество JPEG; оригиналы и варианты «До / После», сохранение точных параметров обработки.
- Отдельный FFmpeg worker: H.264 MP4, 1080×1920 или 1920×1080, 24 fps, плавное приближение, мягкие затемнения, название товара, очередь, статусы и ошибки. Без звуковой дорожки.
- Приватные загрузки с проверкой владельца и Range-запросами для видео. Скачивание отдельных файлов и комплекта ZIP до 150 МБ.
- Один помощник с режимами «Продавец», «Помощник», «Обучение» и серверной историей; это демоалгоритм без вызова модели. Ответы покупателям не отправляются.
- Централизованные лимиты «Базовый»/PRO, счётчики, защищённая админка и PWA с безопасной страницей потери соединения.

## Хранение и сохранность

SQLite находится в **`.davio/davio.sqlite`**, включая файлы в BLOB. Каталог закрыт правами файловой системы и исключён из Git. Для Next.js и worker используется один `DAVIO_DATA_DIR`; оба читают `.env.local`. Не храните эту папку в `public/`. Секреты не должны иметь префикс `NEXT_PUBLIC_`.

Резервная копия: остановите веб-сервер и worker, затем скопируйте **весь каталог `.davio`**, включая существующие WAL/SHM. На другой установке укажите путь через `DAVIO_DATA_DIR`. Копирование Git-репозитория само по себе не переносит аккаунты и материалы. Удаление cookie не удаляет проекты; очистка каталога базы их потеряет.

Архивирование не стирает файлы. Убранные из списка исходники физически остаются в приватном хранилище; интерфейс их полного удаления/возврата из скрытого списка пока не реализован. Архив и скрытые файлы учитываются в лимитах. ZIP — экспорт для публикации, не полная резервная копия аккаунта; автоматического импорта ZIP нет.

Прежние инструменты Seller AI и их localStorage/IndexedDB не очищались и не мигрировали автоматически. Доступны из Настроек и `/legacy/dashboard`; прежние объявления — `/legacy/listings`, сообщения — `/legacy/messages`, настройки магазинов — `/legacy/settings`. Эти старые локальные данные относятся к браузеру, **не защищаются серверным аккаунтом DAVIO**. Описание прежней версии: [docs/LEGACY_README.md](docs/LEGACY_README.md).

## Администрирование

Ни один новый пользователь не становится администратором автоматически. Для уже зарегистрированного локального пользователя владелец установки выполняет:

```bash
npm run admin -- owner@example.com grant
# Отозвать роль: npm run admin -- owner@example.com revoke
```

Затем откройте `/admin`. Там доступны пользователи, назначение тарифа, изменение лимитов, статусы/ошибки задач. Пароли, сессии и чужие материалы в админке не отображаются. Цен, покупок и настоящих платежей нет. Роль меняется только локальным CLI, не публичным API.

## Проверки

```bash
npm run lint
npm run typecheck
npm test
npm run build
python3 tests/check_saas_schema.py
```

Для Playwright установите Chromium: `npx playwright install chromium`, либо задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium`, если используется системный браузер. Проверки запускаются на **отдельной тестовой базе**:

```bash
DAVIO_DATA_DIR="$PWD/work/davio-e2e" npm start
# Второй терминал:
DAVIO_DATA_DIR="$PWD/work/davio-e2e" npm run worker
# Третий терминал:
DAVIO_REUSE_TEST_SERVER=true npm run test:e2e
```

Если тестовый веб-сервер ещё не запущен, `npm run test:e2e` запустит его с отдельной базой автоматически; MP4-проверка в браузере требует отдельно запущенного worker. Переиспользование существующего сервера разрешено только явным `DAVIO_REUSE_TEST_SERVER=true`. Не используйте пользовательскую базу для интеграционных тестов. Результаты последнего прогона — [VERIFICATION.md](VERIFICATION.md).

## API, ограничения и следующие шаги

Контракты расширений: `lib/davio/integrations.ts`; существующие проверяемые адаптеры сравнения моделей: `lib/seller/server/`. Настройка лаборатории описана в [SELLER_AI.md](SELLER_AI.md). Платные запросы выключены; одних ключей недостаточно — нужны проверенные ID моделей, разрешение владельца и явное включение серверной конфигурации. API-ключи никогда не вводятся как ключи в клиентский код или Git.

Распознавание по фото, генеративные фоны/видео, нейросетевая генерация описания и диалогов DAVIO ещё не подключены. Контракт контентного AI предусмотрен, но подключение конкретного провайдера требует реализации и тестирования соответствующего адаптера. Подробности и границы коммерческой готовности — [docs/DAVIO_STATUS.md](docs/DAVIO_STATUS.md).

Облачный `localhost:3000` не является localhost вашего MacBook. В этой среде нет предоставленного инструмента приватного веб-предпросмотра/проброса порта. Публичные туннели и публикация не выполняются. Самый простой бесплатный способ просмотра — запуск актуального исходного кода на MacBook по инструкции выше.
