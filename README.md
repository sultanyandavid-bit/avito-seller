# AI Avito Seller

Рабочий MVP помощника продавца на Next.js, TypeScript и Tailwind CSS. Русский адаптивный интерфейс, без обязательных внешних сервисов, ключей и аккаунта Авито.

## AI-продавец

Новый раздел `/seller`: база знаний, тестовые диалоги, сравнение ответов, ручные оценки, история и расходы. Бесплатный деморежим включён по умолчанию; реальные API заблокированы до явной серверной настройки и разрешения владельца. Полная инструкция и проверенные ссылки на документацию провайдеров — в `SELLER_AI.md`.

## Запуск

Требуется Node.js 20.9+ (рекомендуется 24 LTS) и npm.

```bash
npm ci
npm run dev
```

Откройте http://localhost:3000 на компьютере, где запущен сервер. Для облачной среды и просмотра с MacBook см. `PREVIEW.md`. Для production: `npm run build`, затем `npm start`.
`.env.example` содержит только пустые заготовки будущих серверных переменных. Для MVP копировать его в `.env.local` не требуется. Одних ключей недостаточно: реальные AI-запросы требуют отдельного серверного включения и кода администратора (см. `SELLER_AI.md`).

## Что работает

- **Обзор** `/`: карточки объявлений, непрочитанных сообщений, диалогов и обращений к человеку. Счётчики зависят от локальных данных. Выручка, продажи и график — явно обозначенный статический демопример.
- **Товары** `/products`: создание, редактирование, подтверждаемое удаление; название, описание, цена, категория, остаток, статус и локальные иллюстрации-заглушки. Поиск и фильтр по статусам.
- **Сообщения** `/messages`: четыре русскоязычных диалога, поиск по имени, карточка связанного товара, ручной ответ, непрочитанные сообщения, передача человеку. Переписка сохраняется при удалении товара.
- **AI-ассистент** `/assistant`: переключатель демоподсказок, стиль общения, сохранение будущих инструкций, предпросмотр без отправки. Локальный алгоритм использует актуальную цену, наличие и описание. Скидки, оплата, доставка, возвраты и неизвестные вопросы требуют продавца. Свободные инструкции пока не исполняются: это явно указано в интерфейсе.
- **Настройки** `/settings`: название магазина, город, состояние интеграций, сброс демоданных с подтверждением.

Переключатель «демонстрационные автоответы» разрешает только создание подсказок в переписке. Выбор «Вставить» переносит текст в редактор; отправка всегда ручная. При передаче человеку подсказки в диалоге отключены. Независимый предпросмотр в настройках доступен всегда.

## Данные и ограничения

Данные хранятся в `localStorage` под ключом `ai-avito-seller:v1`, только в текущем браузере и профиле. Серверной БД, авторизации, синхронизации устройств и обмена между вкладками нет. Это демонстрационное рабочее пространство одного пользователя. Не используйте его для реальных персональных данных. Очистка браузера удаляет изменения; сброс в настройках восстанавливает исходный набор.

Сохранённая структура проверяется при загрузке. При недоступном хранилище приложение показывает предупреждение и продолжает работать в памяти. Чтение настроек происходит после монтирования, без серверного доступа к браузерным API.

Авито всегда **«Не подключено»**. В деморежиме приложение не выполняет внешних запросов к AI-провайдерам, не подключает аккаунт и не отправляет сообщений реальным покупателям. Изображения, шрифты и данные не требуют стороннего CDN.

## Структура

```text
app/                  App Router, страницы и адаптивные стили Tailwind/CSS
components/           рабочее пространство, разделы, формы, иллюстрации
lib/types.ts          типизированные модели MVP
lib/demo.ts           исходные товары, диалоги, форматирование рублей
lib/storage.ts        проверка версии и структуры сохранённых данных
lib/assistant.ts      AssistantProvider и безопасный локальный провайдер
tests/               проверки AI-правил и сохранённых данных
```

Будущий OpenAI-провайдер должен реализовать `AssistantProvider` **на сервере**, за аутентифицированным API, с валидацией входных данных и проверкой прав на магазин. Ключи нельзя передавать в клиент или именовать `NEXT_PUBLIC_*`. Текущий интерфейс — точка расширения, а не готовая интеграция. `.env*` исключены из Git, кроме `.env.example`.

## Проверки

```bash
npm run typecheck
npm run lint
npm test
npm run build
# Один раз для браузерных тестов:
npx playwright install chromium
npm run test:e2e
```

При установленном системном Chromium можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium`. Браузерные тесты запускают production-сервер, поэтому сначала нужна сборка.

Тесты проверяют ответы по актуальным ценам/остаткам, передачу сложных вопросов человеку, отсутствие обещаний при удалённом/закончившемся товаре, описание из каталога, стили, восстановление данных и отбрасывание повреждённого состояния. Результаты выполненных проверок приведены в `VERIFICATION.md`.

Для ручной приёмки: создайте товар, измените цену, перезагрузите страницу, проверьте фильтр и удаление; отправьте демоответ; включите подсказки и проверьте передачу продавцу; измените магазин; выполните сброс. Проверьте меню на ширине 375 px.

