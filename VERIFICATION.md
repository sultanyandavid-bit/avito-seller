# Проверка MVP

Проверено 15 октября 2026 (МСК), Node.js 24.19.0, npm 11.9.0, Next.js 16.4.1. Использовался установленный системный Chromium.

- `npm run typecheck` — без ошибок.
- `npm run lint` — без ошибок и предупреждений.
- `npm run build` — успешная production-сборка, статическая генерация всех страниц.
- `npm test` — 7/7 тестов логики пройдено.
- `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e` — 8/8 браузерных проверок пройдено, 4 сценария на двух размерах экрана: 1440×1100 и 375×812.

Браузерные сценарии проверяют:

1. Открытие пяти разделов, отсутствие ошибок JavaScript и горизонтальной прокрутки документа; мобильное меню.
2. Создание и редактирование товара, сохранение после перезагрузки, удаление с подтверждением, сохранность диалога после удаления связанного товара.
3. AI-предпросмотр, вставку текста и ручную отправку, передачу человеку и блокировку подсказок, сохранение настроек магазина и восстановление демоданных.
4. Восстановление после повреждённого localStorage, честный статус «Не подключено», отсутствие внешних запросов при открытии настроек.

Скриншоты главной страницы просмотрены на обоих размерах экрана. Сетевые интеграции, авторизация, реальный Авито, OpenAI и настоящая отправка сообщений отсутствуют и не тестировались.

В начальном запуске песочница запрещала локальные сокеты для Turbopack и запуска тестов. Сборка и проверки повторены с разрешённой сетью среды. Один тест выявил слишком широкое распознавание вопроса «Есть гарантия?» как наличия; правило исправлено. Дополнительная браузерная проверка сначала столкнулась с неоднозначным селектором `alert` из-за встроенного анонсера Next.js; селектор уточнён. Итоговые проверки выше выполнены после исправлений.

## AI-продавец — 16 октября 2026 (МСК)

Реализован отдельный раздел `/seller` и серверные API `/api/seller/providers`, `/api/seller/compare`. Проверки выполнены на Node.js 24.19.0 и production-сборке Next.js 16.4.1.

Итог после исправлений:

- `npm run typecheck` — успешно.
- `npm run lint` — успешно, без предупреждений.
- `npm test` — 23/23 проверок пройдено (7 прежних и 16 новых).
- `npm run build` — успешно, включая новый раздел и два серверных маршрута.
- `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e` — 16/16 проверок пройдено, по 8 на 1440×1100 и 375×812.
- `git diff --check` — успешно.
- Поиск имён серверных credential-переменных в клиентских JS-чанках — 0 совпадений. Это проверка границы сборки; реальные ключи не задавались.

Новые браузерные сценарии: два честно обозначенных демоответа, отсутствие обещания пригодности костюма для −20 °C, ручная оценка и комментарий после перезагрузки, CRUD знаний, сохранность старого каталога, неизменность снимка товара в истории после изменения цены, импорт переписки JSON, сохранение своего сценария, недоступность реальных моделей по умолчанию, обработка 429 и повреждённых данных лаборатории. Прежние сценарии товаров, сообщений, настроек, мобильного меню и восстановления данных также проходят.

Серверные проверки: нормализация usage, расчёт только по заданному тарифу, неизвестные расходы, явные ошибки и таймауты, сохранение usage при пустом ответе, opt-in реального режима, Bearer-код, проверка Origin/Host, ограничения размеров и частоты, проверка провайдеров и защита Qwen endpoint от произвольных URL. Реальные ответы провайдеров заменялись моками; платных обращений не было.

Промежуточные прогоны выявили: оставшийся процесс старого сервера после пересборки; неоднозначное доступное имя селектора сценария; несовпадение канонического request.url Next.js с реальным Host браузера. Сервер перезапущен, полю задано явное доступное имя, проверка источника исправлена без доверия к X-Forwarded-Host. Итоговый полный прогон выполнен после этих исправлений. Скриншоты нового раздела просмотрены на desktop и мобильном экране.

Реальная доступность моделей и тарифов, качество ответов внешних LLM, расход денег и OAuth GigaChat вживую не проверялись. Для этого нужны ключи, серверная конфигурация и отдельное разрешение владельца. Документация API сверена с официальными страницами; ссылки и ограничения приведены в `SELLER_AI.md`.
