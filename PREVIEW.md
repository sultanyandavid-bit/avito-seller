# Предпросмотр приложения

## Диагностика подключения

Причина `ERR_CONNECTION_REFUSED` при проверке в облаке: сервер приложения не был запущен. Браузерные тесты предыдущего этапа запускали временный production-сервер и завершали его после проверок. Успешная сборка сама по себе не оставляет сервер работающим.

`npm run dev` и `npm start` уже слушают `0.0.0.0`. Зависимости и production-сборка присутствуют. Дополнительная конфигурация Next.js не требуется.

Сервер запущен командой `npm start` в удерживаемой сессии облачной среды. Подтверждено прослушивание `0.0.0.0:3000` и HTTP 200 для `/`, `/products`, `/messages`, `/assistant`, `/settings`. Сервер зависит от жизненного цикла облачной сессии и не является постоянным хостингом.

## Доступ с MacBook

`http://localhost:3000` в Chrome на MacBook означает порт на самом MacBook. Облачный сервер имеет собственный loopback. `0.0.0.0` — адрес прослушивания, его нельзя использовать как внешнюю ссылку.

В текущей сессии агенту не предоставлены инструменты веб-предпросмотра, выдачи приватной preview-ссылки или проброса облачного порта. Сетевой proxy среды обеспечивает исходящие запросы и не является входным веб-пробросом. Публикация и сторонние туннели не настраивались. Из этого сеанса нельзя подтвердить доступ из Chrome пользователя к облачному порту.

## Бесплатный способ просмотра на MacBook

Сохраните локальный коммит этой задачи в подключённый GitHub-репозиторий через действие Codex или `git push -u origin work` в облачной среде. Пока push не выполнен, `git clone` не получит эти изменения.

На MacBook установите Node.js 24 LTS, если он ещё не установлен, затем в Терминале:

```bash
git clone --branch work https://github.com/sultanyandavid-bit/avito-seller.git
cd avito-seller
npm ci
npm run dev
```

Для закрытого репозитория понадобится ваш обычный доступ к GitHub. Если репозиторий уже клонирован, используйте существующий checkout и получите ветку `work`.

Не закрывая Терминал, откройте `http://localhost:3000` в Chrome. В этом случае сервер работает на MacBook, поэтому адрес корректен; товары, сообщения и настройки доступны полностью. Для остановки нажмите Ctrl+C.

Если порт 3000 уже занят на MacBook, выполните `npm run dev -- --port 3001` и откройте `http://localhost:3001`.

Переменные окружения, Авито, OpenAI и платные сервисы для просмотра не требуются. Локальные данные браузера в облачных тестах и в Chrome на MacBook независимы.
